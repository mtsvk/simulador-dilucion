# Startup Equity Dilution Simulator

Web simulator for startup equity dilution, featuring investment round calculations, ownership stake visualizations, and local data export.

## Features

- **Investment Round Calculations:** Estimate post-money valuations, dilution percentages, and cap table changes.
- **Visual Stake Breakdown:** View ownership distributions clearly after every funding round.
- **Local Data Export:** Export generated calculations and cap tables directly to your device.
- **Startup Clauses & Terms:** Interactively explore standard startup investment clauses.

## Getting Started

Simply open `index.html` in any modern web browser to run the simulator locally.
